# Real-media qualification

Run from the repository root with `python -m qualification.test_codec_aac SOURCE --stream 1 --temp-dir TEMP --media-root MEDIA` (substitute actual paths). Other modules are ac3, eac3, mp3 and truehd. These are explicit CLI tests, not unittest cases. Baselines are specific to the original specimens and FFmpeg 6.1.1-3ubuntu5. A different encode or decoder may legitimately fail; investigate before changing baselines. TrueHD expects matching PCM with the known quant_step_size diagnostic, not clean decoding. Temporary files are isolated and removed on normal exit or Python exceptions; forced termination may leave them behind. Use a mounted local temporary directory outside the media library and production projects. No publication or timeline certification is performed.
